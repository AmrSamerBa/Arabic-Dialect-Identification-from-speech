ADIS - The Arabic Dialect Identification from Speech AI

Abstract

  • Arabic dialect identification is an interesting problem in the field of NLP.
  • A large gap is present for Arabic dialect identification, not many systems exist.
  • Aiming to bridge that gap by creating a robust Arabic dialect classifier.
  • Fine tuned 3 deep learning models for classifying Arabic dialects.
  • Classifying into 19 Arabic dialects.
  • Trained on data from MIT dataset and manually collected data for Bahrain and Tunisia.
  • Achieved satisfactory accuracy results up to 87% accuracy in the top 1 results.

Dataset construction

  • The dataset for this project combined the ADI-17 dataset from MIT with manually collected data for Bahrain and Tunisia.
  • This comprehensive collection was carefully divided into training and validation.
  • A final testing set to support the development of sophisticated Arabic dialect identification models was collated.
  • Image shows dialects with the number of audio files in Train/Validation/Test format.

System Architecutre

The ‘Data Preprocessing’ state includes chunking the audio files into 10 second segments and waveform extraction.
